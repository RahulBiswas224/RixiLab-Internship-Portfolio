## Skills & Technologies Acquired

Across the eight weeks, I gained hands-on, project-driven experience with:

- **Frontend Development** — React (incl. React 19), server-side rendering with EJS, Tailwind CSS, responsive UI design, and real-time UI updates via Socket.io.
- **Backend Engineering** — Node.js, Express routing, RESTful API design, and MVC architectural structuring.
- **Database Management** — MongoDB & Mongoose (schema design, CRUD, optimized queries) and PostgreSQL with Prisma ORM.
- **Authentication & Security** — JWT-based authentication and secure, server-side payment signature verification.
- **Real-Time Systems** — WebSocket-based live order tracking, chat, and video signaling with Socket.io; peer-to-peer audio/video with WebRTC.
- **Payments** — End-to-end Razorpay integration across two separate projects.
- **Background Processing** — Asynchronous email queues with BullMQ and Redis.
- **Testing** — Automated backend test coverage with Jest and Supertest.
- **Cloud & Deployment** — Provisioning AWS EC2 (Ubuntu) instances, configuring security groups, managing background processes with PM2, and deploying decoupled apps across Vercel, Render, Neon, and MongoDB Atlas.
- **Containerization** — Docker-ready builds for consistent local and deployment environments.
- **Agile Execution** — Meeting strict weekly deadlines and submission requirements via the Rixi Lab dashboard.
